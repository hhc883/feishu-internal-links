# 飞书内链助手（多维表格测试版）

## 安装与连接

1. WordPress「插件 → 安装插件 → 上传插件」，上传 ZIP 并启用。建议先在测试站点使用。
2. 在飞书开放平台创建企业自建应用，开通多维表格查看、评论和导出等足以读取字段和记录的应用身份权限。创建版本并发布，企业管理员按实际流程审批并启用。
3. 打开多维表格，在「…」→「更多」→「添加文档应用」中添加该应用并授予读取权限；如开启高级权限，还需设置对应的数据表访问权限。仅将文档分享给个人账号不等于给应用授权。
4. WordPress「设置 → 飞书内链」中填写应用的 App ID、App Secret 和多维表格 /base/ 链接，保存后点击「同步飞书关键词库」。不要将 App Secret 发到聊天中。
5. 插件使用多维表格自己的 /base/ 链接，不使用嵌入它的外层 /docx/ 文档链接。如果链接不含 table 参数且应用可以访问多张数据表，需要在设置页额外填写目标数据表的 ID（tbl 开头）；只有一张可访问数据表时可留空。
6. 在区块编辑器右上角的更多选项（⋮）打开「飞书内链」，点击「识别内链」，检查匹配列表后点击「确认添加」，最后检查正文并保存。

## 表格字段

字段名称须完全一致：

| 字段 | 类型 | 内容 |
| --- | --- | --- |
| 关键词 | 文本 | 每条记录一个关键词 |
| 内链地址 | 超链接或文本 | 网站本身的完整 http(s) URL |
| 状态 | 单选 | 启用 或 停用 |

示例中的 example.com 地址需要换成 WordPress 站点的实际域名。匹配网址的域名须与 WordPress 首页域名一致。同一关键词不可对应不同 URL；停用记录被忽略。同步任一有效记录有格式错误时，插件提示记录 ID，保留上次成功的规则。空表或没有启用规则会清空已同步规则。同步完成后重新打开编辑器以读取最新规则。

## 匹配范围

仅处理段落和列表项文本，跳过标题、已有链接、代码及其他区块。每个目标 URL 每篇最多一次，每次最多添加 10 条；已有正文链接计入限制，指向当前文章的链接依赖编辑器提供固定链接。匹配不区分英文大小写，英文词首尾按字母、数字和下划线判断边界；不匹配跨多个文本节点的关键词。同一位置优先较长关键词。预览后文章变化时须重新识别。确认后可使用编辑器撤销，并请在发布前检查。

## 注意

多维表格接入尚未在真实授权环境和 WordPress 环境完成端到端验证。插件每天通过 WordPress 定时任务同步一次，也支持手动同步。低流量网站可能延迟执行；若禁用 WP-Cron，需由服务器定时调用 wp-cron.php。同步不修改已有文章。App Secret 保存在 WordPress 数据库，需保护服务器和数据库备份。高级权限或飞书租户限制可能需要管理员额外配置。
